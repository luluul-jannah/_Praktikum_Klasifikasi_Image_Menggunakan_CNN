# _Praktikum_Klasifikasi_Image_Menggunakan_CNN
Klasifikasi Citra Organisme Laut Menggunakan Convolutional Neural Network (CNN) dengan Python dan TensorFlow. Proyek ini bertujuan untuk mengidentifikasi dan mengelompokkan gambar organisme laut berdasarkan kategori melalui proses pelabelan data, preprocessing citra, pelatihan model CNN, serta evaluasi hasil klasifikasi.
